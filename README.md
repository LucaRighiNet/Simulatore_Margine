# Simulatore Margine di Commessa

Strumento a uso dei Project Manager di commessa per simulare il margine al variare dei
macro valori di costo (materiale, manodopera, altri costi diretti) suddivisi per linea di
servizio: quadri elettrici, installazione in cantiere, commissioning.

Il tool confronta tre colonne sulla stessa struttura: Margine preventivo (offerta),
Margine KOM (budget congelato al kick off meeting) e Margine simulato (scenario what-if),
in valore assoluto, in percentuale di marginalità e in punti percentuali.

Contesto: Righi Solutions.
